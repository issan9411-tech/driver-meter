# ドライブメーター

スマホのGPSで現在の時速を表示し、走行距離・燃費・ガソリン代を計算する車載用のWebアプリです。
ホーム画面に追加するとアプリとして使え、一度開けば電波がなくても起動できます。

## できること

- **速度表示**: GPSの時速（km/h）を大きく表示。設定した速度を超えると赤くなり、警告音も鳴らせます
- **トリップ**: 走行距離・経過時間・平均速度（停車中を除く）・最高速度
- **速度の測り方を選べる**（設定タブ）
  - **GPS + センサー**: ふだんはGPSで測り、トンネルなどでGPSが切れたときだけ加速度センサーで推定します。GPSが使える間に「加速度とGPS速度の変化」の関係を自動で学習し、トンネル内での停車も揺れの大きさから判定します。出口では、入口との直線距離で走行距離を補正します
  - **センサーのみ**: GPSを使わず、加速度センサーだけで測ります。止まるたびに 0 km/h に戻し、そのとき残っていた速度をセンサーのかたよりとして補正します。スマホの向きは、先に「GPS + センサー」で走って学習するか、GPSなしでも停車からの発進・停止を4回ほど行うと自動で学習します
- **推定燃料**: 走ったぶんの燃料・ガソリン代・CO₂をメーター画面に表示
- **満タン法の燃費計算**: 走行距離と給油量から km/L を計算し、給油記録として保存。平均燃費も表示
- **ガソリン代の計算**: 距離・燃費・単価から計算。往復や割り勘（人数）にも対応
- **車内向けの表示**: 横向き画面、HUD表示（左右反転でフロントガラスに投影）、昼/夜テーマ、画面の常時点灯、メーター補正（%）
- **デモ走行**: GPSなしで画面の動きを確認

## 使い方

1. スマホで https://issan9411-tech.github.io/driver-meter/ を開きます（GitHub Pages）
2. 「GPSを開始」を押して位置情報を許可します
3. ブラウザのメニューから「ホーム画面に追加」するとアプリとして起動できます

位置情報は `https://` のページでしか使えません。ファイルを直接開いてもGPSは動きません。

センサーを使うときは、スマホをホルダーにしっかり固定してください。iPhone では、最初に画面をタップしたときにセンサー（モーションと画面の向き）の利用許可を確認します。推定値は時間がたつほどずれやすいので、目安として使ってください。

## 公開方法（GitHub Pages）

リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main`、フォルダを `/ (root)` にして保存します。
数分後に https://issan9411-tech.github.io/driver-meter/ で開けるようになります。

## データについて

トリップと給油記録は、その端末のブラウザ（localStorage）にだけ保存されます。外部には送信しません。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体（HTML・CSS・JavaScript を1ファイルに収録） |
| `manifest.webmanifest` | ホーム画面に追加するための設定 |
| `sw.js` | オフラインで起動するためのキャッシュ |
| `icon.svg` / `icon-*.png` / `apple-touch-icon.png` | アプリのアイコン |

## 注意

運転中の画面操作は危険で、法令違反になることがあります。設定や入力は必ず停車中に行ってください。
表示される速度はGPSによる目安です。
